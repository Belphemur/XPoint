# Stats as a First-Class Citizen

**Date:** 2026-09-05
**Status:** Implemented (feat/stats-first-class)
**Related docs:** `2026-08-25-binary-files.md`, `2026-09-01-kindle-wpm-word-count-plumbing.md`,
`2026-09-02-home-card-progress-and-crossink-stats-port.md`, `2026-09-02-global-stats-redesign.md`

## Goal

Reading stats stop being buried menu rows and become first-class surfaces:

1. **Global stats** move out of Settings → System into the home menu with its
   own icon (crossink parity: crossink's home menu has carried this exact row
   — label + chart icon — since its first card-grid port).
2. **Per-book stats** get a dedicated tile on the reader toolbar's tool row,
   next to the Text tool, instead of a row inside the "…" (More) panel.
3. The Home-key "Go Back" shortcut and the home swipe gesture close any open
   reader chrome (toolbar / panel / popup) instead of closing the book.

No reading-stats data model, binary format, or WPM changes. This is
entry-point + navigation work only.

## 1. Global stats on the home menu

- `HomeMenuItem::READING_STATS` inserted after `RECENTS`/`OPDS_BROWSER`,
  before `FILE_TRANSFER` — crossink's exact order (its
  `appendHomeMenuItems`: Browse Files, Recent, [OPDS], Reading Stats, …).
- New `UIIcon::Chart` in `BaseTheme.h`. Lyra maps it to
  `ChartBarIcon` (`src/components/icons/chartbar.h`); BaseTheme and
  RoundedRaff ignore `rowIcon` today, so no changes there.
- **Icon layout gotcha (documented for future icon work):** the legacy home
  menu icons (`folder.h`, `recent.h`, …) are **pre-rotated 90° CCW** —
  `drawIcon` un-rotates at draw time (`GfxRenderer::drawIcon` draws
  `bitmap(row,col)` at `X = size-1-row, Y = col`). Generated icons
  (`gen_icons.py` output, `listIcons.h`) are **upright**. The home icon was
  produced by generating 32px `chart-bar` from Lucide, then rotating CCW
  (`bitmap(r,c) = upright(c, N-1-r)`). The reader-toolbar icon (FreeInkUI
  `BitmapMode::Center` path) uses the upright generated bytes unchanged.
- Routing: `HomeActivity::onReadingStatsOpen()` →
  `ActivityManager::goToGlobalStats()` (pushes `GlobalStatsActivity`; Back
  pops to Home — `GlobalStatsActivity` already exits via `finish()`).
- The row exists only in `READING_STATS_ENABLED` builds (same gate as the
  old settings row). The label reuses the existing `STR_READING_STATS`.

## 2. Settings entry removal

`SettingAction::ReadingStats` (enum value, row push, row-dim guard,
launch case) removed. The global stats viewer is now reachable only from
Home — matching the user's "first-class" direction (stats are a reading
surface, not a system setting).

## 3. Per-book stats on the reader toolbar

- Tool row: Contents, Text, **Stats** (chart icon, `icon_reader_stats_24`
  generated from Lucide `chart-bar`), More — 4 slots when
  `READING_STATS_ENABLED`, 3 otherwise (`kToolCount`).
- Tapping Stats opens a one-row **Stats panel** ("Reading Stats" /
  "Show stats for this book") consistent with the other tool panels;
  activating the row closes the sheet and launches the full-screen
  `BookStatsActivity`. Back from the stats screen returns to the page.
- The More panel (toolbar build) drops the `READING_STATS` row via
  `EpubReaderMenuActivity::buildToolbarMoreItems`; the classic full-screen
  list menu (button boards, non-toolbar style) keeps its row unchanged, and
  `DELETE_STATS` stays in More everywhere.

## 4. Go Back closes reader chrome

- `EpubReaderActivity::handleHomeGesture()` override: when
  `isChromeOpen()` (any overlay or popup), close the sheet
  (`closeOverlayToPage()`) / restore footnote position, and consume the
  gesture; otherwise return false (book-close behavior unchanged).
- `HOME_ACT_GO_BACK` in `main.cpp` routes through
  `ActivityManager::handleBackOnCurrent()` (consume if handled, else
  `popActivity()`), mirroring `openShortcutMenuOnCurrent()`.
- Side effect (accepted): the home swipe gesture with chrome open now also
  closes the sheet rather than leaving the book — consistent semantics for
  every "go back" input on the reading surface.

## What deliberately did not change

- Binary record layout (v6 book / v4 global), WPM algorithm, card-grid
  rendering (`BookStatsView`).
- `GlobalStatsActivity`, `BookStatsActivity` internals.
- The classic list reader menu's stats/delete rows (button boards).
